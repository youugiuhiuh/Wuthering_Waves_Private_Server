# Matrix SDK 0.18 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade matrix-sdk from 0.13 to 0.18 to enable SQLite persistent store, session restore, and E2EE initialization flow.

**Architecture:** Add `sqlite_store(path, passphrase)` to Matrix client builder, implement `restore_session()` → fallback `login_username()` + `save_session()` flow, add `bootstrap_cross_signing_if_needed()` and `wait_for_e2ee_initialization_tasks()` in correct order, persist store passphrase via EncryptedConfig.

**Tech Stack:** matrix-sdk 0.18 (features: rustls-tls, sqlite, e2e-encryption), ruma 0.16, Go crypto/rand

---

### 最终流程

```
Client::builder()
    .homeserver_url(url)
    .sqlite_store(path, passphrase)
    .build()

        │
        ▼
restore_session()
        │
   ┌────┴────┐
   │         │
 成功      失败
   │         │
   │    login_username()
   │         │
   │    save_session()
   │         │
   └────┬────┘
        │

bootstrap_cross_signing_if_needed()    [P2]
   │  (首次 UIAA → Password 重试)
   │  (后续运行 → 无操作)
   ▼
wait_for_e2ee_initialization_tasks()   [P1]
   │  (等待 Device Key / OTK / Megolm)
   ▼
sync_once()

   ▼
get_room() → join/报错 → MatrixAdapter(room)
```

> **顺序关键**：cross-signing 在先，wait_for_e2ee 在后。因为 cross-signing 会触发新的后台任务（密钥上传），先做 cross-signing 再 wait 才能真正等完。

### Task 3: Rewrite Matrix setup in main.rs

**File:** `rust/aegis/src/main.rs:368-406`

**Import changes needed:**
- May need to add `matrix_sdk::ruma::api::client::uiaa` for UIAA AuthData
- May need to adjust the matrix_sdk import line

- [ ] **Write the full Matrix setup block**

Replace lines 368-406 (from `let client = MatrixClient::builder()` to the closing brace before `Some((client, room, matrix_adapter))`) with:

```rust
let store_path = config_dir().join("matrix_store");
let store_passphrase = &matrix_store_passphrase;

let client = MatrixClient::builder()
    .homeserver_url(&matrix_homeserver)
    .sqlite_store(&store_path, Some(store_passphrase))
    .build()
    .await?;

// Try restore existing session first
let session_restored = client.matrix_auth().restore_session().await.is_ok();
if session_restored {
    println!("✅ Matrix 会话恢复成功: {}", matrix_username);
} else {
    // No stored session — login and save
    client
        .matrix_auth()
        .login_username(&matrix_username, &matrix_pwd)
        .initial_device_display_name("Aegis Matrix Bot")
        .send()
        .await?;
    println!("✅ Matrix 登录成功: {}", matrix_username);

    // Save session for future starts
    if let Some(session) = client.matrix_auth().session() {
        // Persist to a file next to config
        let session_path = config_dir().join("matrix_session.json");
        let session_json = serde_json::to_vec(&session)?;
        fs::write(&session_path, session_json)?;
        println!("✅ Matrix 会话已保存");
    }
}

// Bootstrap cross-signing (P2) - first time needs UIAA
if let Err(_) = client.encryption().bootstrap_cross_signing_if_needed(None).await {
    // UIAA required — retry with password
    let password_auth =
        matrix_sdk::ruma::api::client::uiaa::Password::new(
            matrix_sdk::ruma::api::client::uiaa::UserIdentifier::UserIdOrLocalpart(
                matrix_username.clone(),
            ),
            matrix_pwd.clone(),
        );
    let auth_data =
        matrix_sdk::ruma::api::client::uiaa::AuthData::Password(password_auth);
    client
        .encryption()
        .bootstrap_cross_signing_if_needed(Some(auth_data))
        .await?;
}

// Wait for E2EE initialization tasks (P1)
client
    .encryption()
    .wait_for_e2ee_initialization_tasks()
    .await;

client.sync_once(SyncSettings::default()).await?;
```

> **Note:** The exact types (`Password`, `UserIdentifier`, `AuthData`) need to be verified against ruma 0.16 docs.rs. The paths used above are inferred — adjust in implementation.
