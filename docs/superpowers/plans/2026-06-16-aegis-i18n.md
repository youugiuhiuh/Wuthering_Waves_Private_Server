# Aegis I18N Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add zh/en/ja i18n to aegis bot using `i18n` crate, with language switch in main menu and persistence in encrypted config.

**Architecture:** `i18n` crate embeds YAML translations at compile time. A global `RwLock<Lang>` manages current locale. `AppState` stores lang for persistence via `EncryptedConfig`. All hardcoded UI strings replaced with `t!("key")` macro calls. Main menu gets a language switch button row.

**Tech Stack:** Rust 2024, `i18n` crate (YAML backend), `serde`, `tokio`

## Task 1: Create i18n core module

**Files:**
- Create: `rust/aegis/src/core/i18n.rs`
- Modify: `rust/aegis/src/core/mod.rs`

- [ ] **Step 1: Write `src/core/i18n.rs`**

```rust
use serde::{Deserialize, Serialize};
use std::sync::RwLock;

i18n::i18n!("src/resources/i18n");

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum Lang {
    Zh,
    En,
    Ja,
}

impl Lang {
    pub fn as_str(self) -> &'static str {
        match self {
            Lang::Zh => "zh",
            Lang::En => "en",
            Lang::Ja => "ja",
        }
    }

    pub fn from_str(s: &str) -> Self {
        match s {
            "en" => Lang::En,
            "ja" => Lang::Ja,
            _ => Lang::Zh,
        }
    }
}

static CURRENT_LANG: RwLock<Lang> = RwLock::new(Lang::Zh);

pub fn set_lang(lang: Lang) {
    *CURRENT_LANG.write().unwrap() = lang;
}

pub fn lang() -> Lang {
    *CURRENT_LANG.read().unwrap()
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn default_lang_is_zh() {
        assert_eq!(lang(), Lang::Zh);
    }

    #[test]
    fn set_and_get_lang() {
        set_lang(Lang::En);
        assert_eq!(lang(), Lang::En);
        set_lang(Lang::Ja);
        assert_eq!(lang(), Lang::Ja);
        set_lang(Lang::Zh); // restore default
    }

    #[test]
    fn lang_from_str() {
        assert_eq!(Lang::from_str("zh"), Lang::Zh);
        assert_eq!(Lang::from_str("en"), Lang::En);
        assert_eq!(Lang::from_str("ja"), Lang::Ja);
        assert_eq!(Lang::from_str("unknown"), Lang::Zh); // fallback
    }

    #[test]
    fn lang_as_str() {
        assert_eq!(Lang::Zh.as_str(), "zh");
        assert_eq!(Lang::En.as_str(), "en");
        assert_eq!(Lang::Ja.as_str(), "ja");
    }
}
```

async fn save_lang_to_config(state: &Arc<AppState>, lang: i18n::Lang) -> Result<()> {
    let config_dir = config_dir();
    let security = SecurityManager::new(&config_dir.join(KEY_FILE))?;
    let path = config_dir.join(CONFIG_FILE);
    let config_data = fs::read(&path)?;
    let mut encrypted_config: EncryptedConfig = serde_json::from_slice(&config_data)?;
    encrypted_config.lang = Some(lang.as_str().to_string());
    fs::write(path, serde_json::to_vec(&encrypted_config)?)?;
    Ok(())
}
